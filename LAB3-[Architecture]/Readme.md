# Lab 3 — Software Architecture & UML

**Project:** Local Sports Tournament & Bracket Manager

## Objective

Design the software architecture of the tournament management system and
represent its major components, interfaces, and dependencies using a UML
Component Diagram.

## Work Completed

- Selected a **Microservices Architecture**
- Identified major system components
- Defined component interfaces
- Modelled dependencies and interactions
- Created the UML Component Diagram
- Provided architectural justification

## Main Components

- Tournament Management UI
- API Gateway
- Team Management Service
- Tournament & Bracket Service
- Match & Score Service
- Tournament Monitoring Service
- Notification Service
- Tournament Database

## Key Learning

This lab focuses on moving from **what the system should do** to **how the
system should be structured**, using software architecture and UML component
modelling.
